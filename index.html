Humble New Tab Page

Customizable, lightweight new tab page.

Features

  • Bookmarks, most visited, recently closed, and more
  • Simple, clean design
  • Highly customizable
  • Fast loading and lightweight

Download for Chrome
Download for Firefox

This extension replaces your new tab page. Drag and drop or right-click to edit the page. The font, colors, background, and more can be customized.

The source code is available on GitHub under the MIT license.
